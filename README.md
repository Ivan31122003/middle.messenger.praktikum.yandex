# Мессенджер

[Открыть приложение](https://practicum-messenger-shestiv.netlify.app)

Учебный проект мессенджера. Приложение содержит страницы авторизации, регистрации, списка чатов и профиля пользователя, а также страницы обработки ошибок.

## Страницы

- `/login` — вход в аккаунт;
- `/registration` — регистрация;
- `/messenger` — мессенджер;
- `/profile` — профиль пользователя;
- `/5xx` — страница ошибки сервера;
- `/` — перенаправление на `/login`.

Для неизвестных адресов отображается страница 404.

## Запуск и сборка

Требуется Node.js версии 22 или новее.

Для запуска dev-сервера:

```bash
npm install
npm run dev
```

Для проверки production-сборки и её запуска локально:

```bash
npm run start
```
