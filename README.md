# Мессенджер

[Открыть приложение](https://practicum-messenger-shestiv.netlify.app)

Учебный проект мессенджера. На текущем этапе реализована вёрстка страниц авторизации, регистрации, списка чатов, профиля пользователя и страниц ошибок. Данные и навигация временно замоканы; полноценная логика будет добавлена в следующих спринтах.

## Страницы

- `/login` — вход в аккаунт;
- `/registration` — регистрация;
- `/messenger` — мессенджер;
- `/profile-info` — просмотр профиля;
- `/profile-change-data` — изменение данных профиля;
- `/profile-change-password` — изменение пароля;
- `/5xx` — страница ошибки сервера;
- `/` — перенаправление на `/login`.

Для неизвестных адресов отображается страница 404.

## Требования

Требуется Node.js версии 22 или новее.

## Установка и запуск

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```

Собрать проект и запустить локальный preview-сервер:

```bash
npm run start
```
