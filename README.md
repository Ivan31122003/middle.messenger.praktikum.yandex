# Мессенджер

Учебный клиент мессенджера. Проект реализован как одностраничное приложение на TypeScript с компонентным подходом, шаблонами Handlebars и клиентской маршрутизацией.

**Демо:** [Netlify](https://practicum-messenger-shestiv.netlify.app)

## Возможности

- страницы авторизации, регистрации, мессенджера, профиля и ошибок;
- регистрация, вход и выход через HTTP API Яндекс Практикума;
- получение списка чатов, создание чата и выбор активного чата;
- добавление и удаление пользователей в активном чате по логину;
- просмотр и изменение данных профиля и пароля;
- загрузка и отображение аватара пользователя;
- клиентская валидация полей формы;
- обработка отправки форм без перезагрузки страницы;
- клиентский роутинг с проверкой авторизации и страницей 404 для неизвестных адресов;
- модальные окна и уведомления о результатах операций.

Отправка и получение сообщений пока не реализованы. Форма сообщения выполняет клиентскую валидацию и выводит значения в консоль.

## Страницы

| Маршрут                     | Описание                    |
| --------------------------- | --------------------------- |
| `/`                         | Вход в аккаунт              |
| `/sign-up`                  | Регистрация                 |
| `/messenger`                | Список чатов и активный чат |
| `/settings`                 | Просмотр профиля            |
| `/settings-change-data`     | Изменение данных профиля    |
| `/settings-change-password` | Изменение пароля            |
| `/404`                      | Страница не найдена         |
| `/500`                      | Страница серверной ошибки   |

Без авторизации доступны только `/` и `/sign-up`; остальные адреса перенаправляют на страницу входа. Авторизованный пользователь при открытии страницы входа или регистрации перенаправляется на `/messenger`. После успешной регистрации или входа также открывается `/messenger`. Для неизвестных адресов авторизованному пользователю отображается страница 404.

## Стек и инструменты

- TypeScript;
- Vite;
- Handlebars;
- Sass (SCSS);
- ESLint и typescript-eslint;
- Stylelint;
- Prettier;
- dotenv для загрузки переменных окружения в конфигурации Vite.

Компоненты построены на базовом классе `Block`. Он отвечает за рендеринг Handlebars-шаблонов, вложенные компоненты, обработчики событий, refs и обновление props.

HTTP-запросы выполняются собственным классом `HTTPTransport` на основе `XMLHttpRequest` и `Promise`. Поддерживаются методы `GET`, `POST`, `PUT`, `DELETE`, параметры query string, JSON и `FormData`. Запросы отправляются с cookies (`withCredentials`). API-классы находятся в `src/api`, контроллеры — в `src/controllers`, общее состояние пользователя и чатов — в `src/core/store`.

## Клиентская маршрутизация

Навигация реализована классами `Router` и `Route` в `src/core/navigation`. Общий экземпляр `router` создаётся в `app-router.ts` и экспортируется из `@/core/navigation`.

Маршруты регистрируются в `src/main.ts` после регистрации компонентов и шаблонов:

```ts
router.use('/', LoginPage).use('/sign-up', RegPage).use('/messenger', MessengerPage);

router.start();
```

Метод `use()` принимает адрес и класс страницы. `start()` открывает страницу по текущему URL и подключает обработку кнопок браузера «Назад» и «Вперёд». Для неизвестного адреса используется зарегистрированный маршрут `/404`.

Для перехода из компонента используйте общий экземпляр роутера:

```ts
import { router } from '@/core/navigation';

router.go('/messenger');
```

Метод `go()` обновляет адрес через History API и отображает страницу без перезагрузки. Роутер перехватывает обычные клики по внутренним ссылкам на зарегистрированные маршруты. При самостоятельном вызове `go()` из обработчика ссылки отменяйте стандартный переход через `event.preventDefault()`.

`Route` создаёт экземпляр страницы при первом открытии и сохраняет его для повторного использования. Настройка `rootQuery` задаёт CSS-селектор контейнера (по умолчанию `#app`). Функция `render()` из `src/core/utils/renderDOM.ts` вставляет элемент страницы в контейнер через `replaceChildren()`. Методы `Block.show()` и `Block.hide()` управляют атрибутом `hidden` корневого элемента.

## Требования

- Node.js 22 или новее;
- npm.

## Установка

```bash
npm install
```

Создайте файл `.env` в корне проекта:

```dotenv
VITE_BACKEND_HOST=https://ya-praktikum.tech
PORT=3000
```

`VITE_BACKEND_HOST` — обязательный адрес API без завершающего `/` и без `/api/v2`: пути добавляются API-классами. `PORT` — необязательный порт сервера разработки, по умолчанию `3000`. После изменения переменных перезапустите сервер разработки или пересоберите приложение. Файл `.env` исключён из Git.

## Команды

### Разработка

```bash
npm run dev
```

Запускает Vite dev-сервер. По умолчанию приложение открывается на `http://localhost:3000`.

### Проверки качества

```bash
npm run lint
```

Последовательно запускает:

- проверку типов TypeScript (`tsc --noEmit`);
- ESLint;
- Stylelint для SCSS-файлов.

### Production-сборка

```bash
npm run build
```

Сначала проверяет типы, затем собирает проект Vite в каталог `dist`.

### Локальный запуск production-версии

```bash
npm run start
```

Собирает проект и запускает Vite preview на порту `3000`.
